# Android-застосунок «Автокошик НБУ»

## Використання

1. Натисніть **НБУ / Вхід** і самостійно увійдіть у магазин.
2. Вставте одне чи декілька посилань на конкретні товари. Кожне посилання — з нового рядка.
3. Натисніть **Запустити** та залиште застосунок відкритим на екрані.
4. Застосунок перевіряє сторінки кожну 1 секунду. Після появи активної кнопки покупки він натисне її один раз, зупиниться й подасть сигнал.
5. Перейдіть до кошика та самостійно оформіть замовлення.

Кнопка **Оновити** перевіряє останній GitHub Release, завантажує новий APK і відкриває системне підтвердження встановлення. Під час першого використання Android попросить дозволити застосунку встановлювати власні оновлення.

Застосунок не вводить пароль, не оплачує замовлення та не обходить CAPTCHA або інші обмеження магазину.

## Збирання APK

1. Встановіть Android Studio з Android SDK 35.
2. Відкрийте папку `android-app` як проєкт.
3. Дочекайтеся завершення Gradle Sync.
4. Оберіть **Build → Build APK(s)**.
5. APK буде створено в `app/build/outputs/apk/debug/app-debug.apk`.
